🤖 AI 응원 댓글 기능

가계부·결산·부수입 인증을 올리면 AI가 따뜻한 응원 댓글을 자동으로 써줘요. 단톡방에 바로 복사해서 붙여넣을 수 있어요. Google Gemini API 키가 있어야 사용할 수 있어요.

Gemini API 키

API 키 발급받는 법

  1. Google AI Studio에 접속 후 구글 계정으로 로그인
  2. "Create API key" 버튼 클릭
  3. 생성된 키를 복사해서 위 입력창에 붙여넣고 저장
🔒 입력한 키는 이 브라우저에만 저장돼요. AI 요청은 여러분의 브라우저에서 Google로 직접 전송되고, 별도 서버를 거치지 않아요. 다만 공용 PC에서는 사용 후 키를 삭제해주세요.
