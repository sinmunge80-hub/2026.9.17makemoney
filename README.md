# 메이크머니 해빗챌린지 — 브랜드 홈페이지 + 인증 웹앱

카페 없이도 하나의 사이트에서 브랜드를 소개하고, 매일 저녁 단톡방에 사진으로
올리던 가계부 인증까지 할 수 있게 만든 사이트입니다.

- 🏡 **브랜드 홈페이지** (`index.html`): 소개, 블로그·브런치·Threads 링크,
  협업 문의 폼, 향후 출시할 "메이크머니 해빗노트" 알림 신청까지 한곳에
- ✅ **일일 가계부 인증**: 고정지출/변동지출 구분 입력 + 사진 + 한줄 소감
- 📊 **주간/월간 결산 인증**: 자동 합계 통계 + 결산 소감 인증
- 💵 **부수입 인증**: 금액 + 카테고리(증권사/은행 이벤트, 앱테크, 캐시백, 배당금,
  공모주, 부업, 중고거래, 환테크 등) + 출처 기록, 이번 달 합계와 카테고리별 비중
  그래프 자동 집계 — 편한가계부 등 다른 가계부 앱에 따로 입력할 필요 없이
  여기서 한 번에 기록할 수 있어요
- 📋 **챌린지 대시보드**: 오늘 인증한 사람, 연속 인증일수 순위, 이번 달 참여왕
- 🔗 **정보허브**: 부수입 링크, 추천 유튜브 채널을 정리하고, 챌린지원들이 직접
  유용한 사이트·부수입 사이트를 추가로 공유할 수 있어요
- 🎯 **과제·미션 게시판**: 운영자가 "N주차 N일차" 형식으로 매일 과제를 올리면,
  챌린지원들이 버튼 한 번으로 완료 인증을 하고 댓글로 소통할 수 있어요.
  이달의 추천 도서 2권도 같은 페이지에서 소개해요
- 💬 **질문게시판**: 궁금한 점을 남기면 운영자와 다른 챌린지원이 답글로 답변해요
- 🙌 **댓글(응원/피드백)**: 각자의 가계부 인증에 댓글을 달아 서로 동기부여하고,
  운영자가 하루 피드백을 남길 수 있어요
- 🔑 **구글 로그인**: 구글 계정으로 로그인하면 닉네임이 자동으로 채워지고,
  질문게시판·댓글에서 운영자 답변이 배지로 구분돼요 (선택 사항)
- 🤖 **AI 응원 댓글**: 인증할 때마다 Gemini AI가 따뜻한 응원 댓글을 자동으로 써줘요.
  단톡방에 바로 복사해서 붙여넣을 수 있어요.

**사이트 구조**: `index.html`(브랜드 홈)이 사람들이 처음 만나는 대문이고,
여기서 "오늘의 인증하러 가기"를 누르면 `challenge.html`(챌린지 대시보드)로
들어가 일일/결산/부수입 인증을 할 수 있어요. 앱 안 어디서든 상단의 사이트
제목을 누르면 다시 브랜드 홈으로 돌아옵니다.

코딩 지식이 없어도 아래 순서대로 따라 하면 됩니다. (전체 약 15~20분)

## 1단계. 우선 그냥 열어보기 (로컬 체험 모드)

`index.html` 파일을 더블클릭해서 브라우저로 열면, 별도 설정 없이도 바로
써볼 수 있어요. 다만 이 상태에서는 **내 폰(브라우저)에만** 기록이 저장되고
다른 사람과 공유되지 않아요. (인증 화면 상단에 "📱 로컬 체험 모드" 표시가 떠요)

챌린지원들과 실제로 함께 쓰려면 2~3단계를 진행해서
- 데이터가 실시간으로 공유되고
- 아무나 링크만 누르면 접속할 수 있게

배포까지 완료해야 합니다.

## 2단계. Firebase 연결하기 (무료 Spark 요금제, 코딩 없음, 약 10분)

여러 사람이 같은 데이터를 보려면 클라우드 저장소가 필요해요. 구글의
**Firebase**를 쓰면 **Spark(무료) 요금제** 안에서, 코드 한 줄 안 쓰고 설정할
수 있어요. 이 사이트는 **Firestore(데이터베이스)**와 **Authentication(구글
로그인)**만 사용하고, 결제수단 등록이 필요한 **Storage(파일 저장소)는 쓰지
않아요** — 사진은 작게 압축해서 Firestore 안에 직접 저장하기 때문에 무료
요금제만으로 충분합니다.

1. [Firebase 콘솔](https://console.firebase.google.com/) 접속 → 구글 계정으로 로그인
2. **프로젝트 추가** 클릭 → 프로젝트 이름 입력 (예: `makemoney-challenge`) → 계속 진행 (Google Analytics는 꺼도 됩니다)
3. 프로젝트가 만들어지면, 왼쪽 메뉴에서 **빌드 → Firestore Database** 클릭 → **데이터베이스 만들기**
   - 위치는 `asia-northeast3 (서울)` 선택
   - 보안 규칙은 우선 **테스트 모드로 시작** 선택 (아래 3단계에서 규칙을 다시 손봐요)
4. 왼쪽 메뉴 상단 톱니바퀴(프로젝트 설정) → 아래로 스크롤 → **내 앱** 섹션에서
   `</>` (웹) 아이콘 클릭 → 앱 닉네임 입력 (예: `web`) → **앱 등록**
5. 화면에 나오는 `firebaseConfig` 값을 복사합니다. 아래처럼 생겼어요.

   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "makemoney-challenge.firebaseapp.com",
     projectId: "makemoney-challenge",
     storageBucket: "makemoney-challenge.firebasestorage.app",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abcdef",
   };
   ```

6. 이 저장소의 `js/firebase-config.js` 파일을 열어서, 복사한 값으로 그대로
   교체하고 저장하세요. (`storageBucket` 값도 그대로 넣어두면 되는데, 실제
   Storage 기능은 사용하지 않아요)

이제 앱을 새로고침하면 상단 배지가 "☁️ 실시간 동기화"로 바뀌고, 다른
사람이 입력한 인증도 함께 보이게 됩니다.

### 구글 로그인 켜기 (선택)

1. Firebase 콘솔 → 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. **Sign-in method** 탭 → **Google** 선택 → **사용 설정** 켜기 → 프로젝트 지원
   이메일 선택 → **저장**
3. 같은 화면(Authentication) → **Settings** 탭 → **승인된 도메인**에서
   **도메인 추가** → 실제 배포한 주소(예: `makemoneyhabitchallenge.netlify.app`)를
   추가해주세요. (`localhost`는 이미 기본으로 들어가 있어서 로컬 테스트는
   바로 됩니다)

이 두 가지를 안 하면 로그인 버튼을 눌러도 오류가 나니 꼭 해주세요. 구글
로그인은 켜지 않아도 나머지 기능은 그대로 다 쓸 수 있어요.

## 3단계. 보안 규칙 설정하기 (중요! 꼭 하세요)

테스트 모드는 30일이 지나면 자동으로 데이터를 막아버려요. 그리고 아무나
데이터를 지울 수도 있어서, 아래 규칙으로 바꿔주는 걸 추천해요.

**Firestore 규칙** (Firestore Database → 규칙 탭에 붙여넣기)

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /entries/{entryId} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if false;
    }
  }
}
```

> 가계부 인증, 질문게시판, 댓글, 커뮤니티 링크 추천이 모두 같은
> `entries` 컬렉션 안에 `category` 값으로 구분되어 저장되기 때문에, 규칙은
> 이 하나로 전부 적용돼요. 누구나 읽고 새 글을 올릴 수 있지만, 기존 기록은
> 지우거나 수정할 수 없게 만들어줘요. 단톡방 링크로만 공유하는 소규모
> 챌린지에 적합한 간단한 설정입니다.

## 4단계. 배포해서 링크로 공유하기

Firebase에 연결까지 끝났다면, 이제 이 폴더를 무료 호스팅에 올려서
챌린지원들에게 링크 하나로 공유할 수 있어요. **GitHub Pages**를 추천해요 —
완전 무료이고, Netlify/Vercel과 달리 빌드 횟수·크레딧 제한이 없어서 이
사이트처럼 자주 업데이트해도 걱정 없어요.

### GitHub Pages로 배포하기 (추천)

1. 이 저장소 페이지 상단 **Settings** 탭 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Build and deployment → Source**를 **Deploy from a branch**로 선택
4. **Branch**를 `main`, 폴더를 `/ (root)`로 선택 → **Save**
5. 1~2분 기다리면 같은 화면에 `https://<깃허브아이디>.github.io/<저장소이름>/`
   형태의 주소가 떠요. 이 주소를 단톡방에 공유하면 끝!
6. 이후 `main` 브랜치에 새 커밋이 올라올 때마다 자동으로 재배포돼요.

> ⚠️ 주소가 바뀌면 **Firebase 콘솔 → Authentication → Settings → 승인된
> 도메인**에 새 주소의 도메인 부분(예: `깃허브아이디.github.io`)을 꼭
> 추가해주세요. 안 하면 구글 로그인이 안 돼요.

### Vercel / Netlify를 쓰고 싶다면

두 서비스 모두 무료 플랜이 있지만, 무료 크레딧(빌드 횟수)을 다 쓰면
새로운 커밋을 올려도 자동 배포가 멈추는 경우가 있어요. 이 경우 화면에
관련 안내 배너가 뜨는지 확인하시고, 뜬다면 GitHub Pages로 옮기시는 걸
추천해요.

1. [vercel.com](https://vercel.com) 에서 GitHub 계정으로 가입/로그인
2. **Add New → Project** → 이 저장소(`2026.9.17makemoney`) 선택 → **Deploy** 클릭
   (프레임워크 설정 없이 그대로 두면 됩니다 — 정적 파일이라 빌드 과정이 필요 없어요)
3. 배포가 끝나면 `https://your-project.vercel.app` 같은 주소가 생겨요.

## 5단계. 브랜드 홈 & 정보허브 내용 채워넣기

**브랜드 홈페이지**: `js/profile-data.js` 파일을 열면 소개 문구, 블로그·
브런치스토리·Threads·오픈채팅 링크, 협업 문의용 이메일, "메이크머니 해빗노트"
소개 문구를 모두 여기서 관리할 수 있어요. 값만 바꿔서 저장하면 `index.html`에
바로 반영됩니다. (`url: "#"`으로 되어 있는 항목은 실제 링크 주소로 꼭
바꿔주세요)

**정보허브**: `js/links-data.js` 파일을 열면 부수입 링크, 추천 유튜브 채널
등을 카테고리별로 정리할 수 있어요. 마찬가지로 `title`, `desc`, `url` 값만
바꿔서 저장하면 됩니다. (이 외에 챌린지원들이 직접 추가하는 추천 사이트는
정보허브 화면에서 바로 등록하면 됩니다)

**운영자 표시**: `js/profile-data.js`의 `operatorEmail`(구글 로그인용 본인
이메일) 또는 `operatorNickname`(직접 쓰실 닉네임)을 채워두면, 질문게시판과
댓글에서 운영자님의 답변에 "운영자" 배지가 자동으로 붙어요. 구글 로그인을
켜셨다면 `operatorEmail`이 훨씬 안전해요 (닉네임은 다른 사람도 똑같이 입력할
수 있지만, 이메일은 로그인해야만 일치하거든요).

> 홈페이지의 **협업 문의**와 **해빗노트 알림 신청** 폼으로 들어온 내용은
> 가계부 인증과 같은 방식(Firebase `entries` 컬렉션)으로 저장돼요. Firebase
> 콘솔 → Firestore Database → `entries`에서 `category`가 `inquiry`(문의) 또는
> `waitlist`(알림 신청)인 문서를 찾으면 확인할 수 있어요. (Firebase를 아직
> 연결하지 않았다면 로컬 체험 모드라 본인 브라우저에만 저장돼요)

## 6단계. AI 응원 댓글 기능 켜기 (선택, 무료)

인증할 때마다 AI가 자동으로 따뜻한 응원 댓글을 써주는 기능이에요. 켜지 않아도
나머지 기능은 그대로 다 쓸 수 있어요.

1. 앱 오른쪽 위 **⚙️ 설정** 아이콘 클릭 (또는 `settings.html` 접속)
2. **Google AI Studio** 링크 클릭 → 구글 계정으로 로그인 → **Create API key** 클릭 →
   생성된 키 복사 (`AIza...`로 시작)
3. 설정 화면의 입력창에 붙여넣고 **저장하기** 클릭
4. **키 테스트하기** 버튼으로 정상 연결됐는지 확인

이후 일일/주간·월간/부수입 인증을 완료하면 바로 아래에 "🤖 AI 응원 댓글" 카드가
뜨고, **복사하기** 버튼으로 단톡방에 바로 붙여넣을 수 있어요.

> 🔒 API 키는 이 브라우저(폰/PC)에만 저장돼요. AI 요청은 브라우저에서 Google로
> 직접 전송되며, 이 앱을 만든 사람을 포함해 누구의 서버도 거치지 않아요.
> 각 챌린지원이 개인 폰에서 각자 키를 등록해도 되고, 운영자 폰에서만 켜서
> 운영자가 답글 문구를 받아 복사해 올리는 방식으로 써도 돼요.
>
> Google Gemini API는 무료 사용량 한도 안에서는 비용이 들지 않지만, 사용량이
> 많아지면 유료로 전환될 수 있으니 [Google AI Studio](https://aistudio.google.com/app/apikey)에서
> 본인 사용량을 가끔 확인해주세요.

## Firebase 무료(Spark) 요금제 안에서 안전한 이유

- **결제수단 등록이 필요 없는 서비스만 사용**: Firestore(데이터베이스)와
  Authentication(로그인)만 쓰고, 결제수단을 요구하는 Storage나 Cloud
  Functions는 전혀 쓰지 않아요. 사진은 작게 압축해서 Firestore 문서 안에
  바로 저장합니다.
- **Firestore Spark 무료 한도**: 저장용량 1GiB, 읽기 하루 5만 회, 쓰기 하루
  2만 회, 삭제 하루 2만 회 — 소규모 챌린지 커뮤니티(수십~수백 명)가 매일
  써도 여유 있게 남는 수준이에요.
- **Authentication(구글 로그인)**: 이메일/구글 로그인은 Spark 요금제에서도
  완전히 무료예요.
- 다만 커뮤니티가 아주 커지면(수천 명 이상, 게시물 수만 건) 한도에 가까워질
  수 있으니, 그때는 Firebase 콘솔의 사용량 화면에서 가끔 확인해주세요.

## 참고

- 사진은 자동으로 축소·압축되어 Firestore 문서 안에 저장돼요. 너무 큰
  사진은 여러 단계로 더 압축을 시도하고, 그래도 안 되면 "사진 없이" 나머지
  내용만 저장돼요 (이때는 저장 완료 메시지에 안내가 함께 떠요).
- 로컬 체험 모드에서는 모든 데이터가 이 브라우저에만 저장돼요 — 실제 운영은
  꼭 Firebase 연결을 권장해요.
- 닉네임은 브라우저에 저장돼서 다음 방문 때 자동으로 채워집니다. 구글
  로그인을 하면 로그인한 구글 계정 이름으로 자동으로 채워져요.
- AI 응원 댓글 기능은 Gemini API 키를 등록한 브라우저에서만 동작해요. 키를
  등록하지 않았다면 인증 폼 아래에 안내 문구만 보이고, 나머지 기능은 모두
  평소처럼 사용할 수 있어요.
- 질문게시판과 가계부 댓글은 같은 방식으로 동작해요 — 누구나 답글을 남길 수
  있고, 운영자로 등록한 이메일/닉네임으로 작성하면 "운영자" 배지가 붙어요.
- 과제·미션은 기술적으로는 누구나 등록할 수 있지만(질문게시판과 동일한
  방식), 화면에 "운영자님만 등록해주세요" 안내 문구가 있어서 실제로는
  운영자만 올리는 걸 전제로 만들었어요. 주차는 1~4주차 중에서 자유롭게
  고르시면 되니, 3주 프로그램이든 4주 프로그램이든 그대로 쓰시면 돼요.
- 이달의 도서는 `js/monthly-books.js`에서 title/author/desc/url 값만
  바꿔주시면 돼요. 책을 2권보다 늘리고 싶으면 배열에 객체를 추가하면 됩니다.
